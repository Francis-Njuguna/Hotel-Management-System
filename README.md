# Hotel Management System

Chuka University · Department of Computer Science · ACSC 483 / COSC 482 project.

**Current milestone: discovery for owner review.** This repository currently contains project planning and OpenCode team configuration. There is no application to run yet. The [discovery report](docs/discovery_report.md) sets out the proposed system, evidence, trade-offs and decisions needed before requirements sign-off.

The intended application uses React/TypeScript, Django REST Framework and PostgreSQL. Its first complete workflow will follow a room from booking and arrival through service charges, settlement, departure and inspection. The dashboard will report on these same operational records. Academic findings must come from actual investigation; source artwork, identifying research records and guest/payment data do not belong in this public repository.
